                            Cách xuất bản ứng dụng này thành đường link công khai miễn phí trong 2 phút:
                        

                        
Vì toàn bộ mã nguồn được đóng gói độc lập trong 1 file index.html duy nhất, bạn có thể xuất bản lên bất kỳ nền tảng miễn phí nào dưới đây để lấy link gửi cho giảng viên hoặc khách hàng:

                    


                    

                        
                        

                            

                                Nhanh nhất (30 giây)
                            

                            
Cách 1: Netlify Drop

                            
    
                                
  1. Lưu mã nguồn này thành file tên index.html trong một thư mục.
    2. 
                                
  2. Truy cập app.netlify.com/drop.
    3. 
                                
  3. Kéo thả thư mục chứa file vào trình duyệt.
    4. 
                                
  4. Nhận ngay đường link dạng https://lumina-fashion.netlify.app để gửi!
    5. 
                            

                        


                        
                        

                            

                                Chuẩn nộp đồ án
                            

                            
Cách 2: GitHub Pages

                            
    
                                
  1. Tạo repository mới trên GitHub.com (chế độ Public).
    2. 
                                
  2. Tải file index.html lên repository đó.
    3. 
                                
  3. Vào Settings → Pages, chọn nhánh main và nhấn Save.
    4. 
                                
  4. Lấy link https://username.github.io/ten-repo (kèm luôn link mã nguồn!).
    5. 
                            

                        


                        
                        

                            

                                Tốc độ cao
                            

                            
Cách 3: Vercel

                            
    
                                
  1. Đăng nhập Vercel.com bằng tài khoản GitHub.
    2. 
                                
  2. Chọn Add New → Project và Import repo vừa tạo ở Cách 2.
    3. 
                                
  3. Nhấn Deploy (không cần cấu hình thêm).
    4. 
                                
  4. Nhận link https://lumina-fashion.vercel.app hoạt động mượt mà trên mọi thiết bị.
    5. 
                            

                        

                    


                    

                        
Lưu ý về API Key khi chạy ngoài môi trường Canvas:

                        
Khi mở trên môi trường hiện tại, hệ thống tự động cấp phát quyền gọi Gemini API. Nếu bạn xuất bản file index.html ra hosting bên ngoài (Netlify/GitHub Pages), bạn chỉ cần lấy 1 API Key miễn phí tại aistudio.google.com và dán vào biến const apiKey = "YOUR_API_KEY"; trong mã nguồn (hệ thống cũng tích hợp sẵn chế độ dự phòng thông minh đảm bảo không bao giờ bị lỗi trống màn hình).
